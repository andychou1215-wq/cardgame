# 卡牌效果
- 抽牌: 從牌組最頂端拿取一張牌。
- 傷害: 扣除生命值。
- 治療: 恢復受到傷害扣除的現有生命值。
    * 治療不能使目前生命值超過最大生命值。
- 增加攻擊: 單位增加攻擊值。
- 增加生命: 單位增加最大生命值，現有生命值也會同步增加。
- 召喚: 新增單位至戰場。
    * 召喚是使單位登場的一種方式，但登場不等於召喚。
- 棄牌: 將手牌中的卡牌移至棄牌區。
- 回手: 將卡牌從目前區域移回擁有者手牌。
- 指定: 發動時選擇合法遊戲物件。
- 影響: 結算時作用於符合條件物件。
- 死亡: 單位因現有生命值歸零離場。
- 摧毀: 單位因效果離場。
    * 摧毀不算死亡。
    * 最大生命變成0時視為摧毀
- 離場: 單位由戰場移動至其他區域。

# 效果觸發時機
- 登場時
    * 單位以正常使用單位、效果召喚或特殊方式進入戰場時視為登場。
- 翻牌時
- 攻擊時
- 受到攻擊時
- 死亡時
- 離場時
    * 所有死亡皆視為離場；並非所有離場皆視為死亡。
- 回合開始時
- 回合結束時

# 回應系統
- 只有回應卡可以回應。
- 任意卡牌發動卡牌效果或單位卡發動攻擊時，優先由非行動玩家取得回應權，若其無法或選擇不回應，則立即關閉回應窗口。
- 任一觸發效果進入待結算狀態後，依一般效果規則開啟回應窗口。
- 玩家輪流獲得回應權。
    - 原始行動之後，非行動玩家可使用一次回應卡，行動玩家可再使用一次回應卡，此後關閉回應窗口。
- 回應結算後，若原本效果目標因回應效果變成不合法，則原本效果將變為無效。
    - 若效果的所有目標皆不合法，效果無效；若仍有合法目標，只對合法目標結算。

# 效果結算
- 多個效果依發動時間順序結算(後發動先結算)，且玩家都不回應後才開始結算
- 結算過程不能插入新效果
- 多個效果同時觸發時，依卡牌進場順序決定結算優先級，後進場者優先結算。
