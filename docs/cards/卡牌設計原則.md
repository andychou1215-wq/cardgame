# 卡牌基本數值
- 卡牌名稱
- 卡牌類型
- 魔力費用
    - 預設最低1，最高12
- 攻擊力
    - 正面預設最低1，最高8
    - 反面預設最低3，最高12
- 生命值
    - 現有生命值
        - 會因傷害扣除，可用治療效果恢復。
    - 最大生命值
        - 正面預設最低1，最高8
        - 反面預設最低3，最高12
- 效果
    - 正面效果
    - 反面效果
- 稀有度
    - R、SR、UR

# 正反面機制
- 單位卡都先以正面登場，達成指定條件時才可翻至反面。
- 翻面不需要消耗魔力。
- 達成條件後由玩家選擇是否翻面。
- 一回合翻牌次數不限。
- 翻面不算「登場」。
- 翻面後可以立即攻擊，但不能直接攻擊玩家。
- 翻面後保留傷害值，而不是直接回滿生命。
- Buff / Debuff 保留。
- 翻面後不能翻回正面。
- 反面被回手後回到手牌時是正面。
