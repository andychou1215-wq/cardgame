# 卡牌基本數值
- 卡牌名稱
- 卡牌類型
- 魔力費用
    - 預設最低1，最高12
- 攻擊力
    - 預設最低1，最高12
- 生命值
    - 現有生命值
        - 會因傷害扣除，可用治療效果恢復。
        - 現有生命值不能高於最大生命值；若最大生命值降低至低於現有生命值，現有生命值同步降至新的最大值。
    - 最大生命值
        - 預設最低1，最高12
- 效果
    - 正面效果
    - 反面效果
- 稀有度
    - R、SR、UR

# 正反面機制
- 單位卡都先以正面登場，達成指定條件時才可翻至反面。
- 單位達成翻面條件後進入「可翻面」狀態。其控制者可於自己具有行動權時選擇將其翻面。
- 翻面不需要消耗魔力。
- 達成條件後由玩家選擇是否翻面。
- 每回合可有任意數量的單位翻面；每張單位在留場期間僅能由正面翻至反面一次。
- 翻面不算「登場」。
- 翻面後可以立即攻擊，但不能直接攻擊玩家。
- 翻面後保留傷害值，也不回滿生命。
- Buff / Debuff 保留。
- 反面被回手後回到手牌時是正面，重新進場時所有累積條件將重新計算。
- 翻面本身不能被阻止，但翻面造成的觸發效果可以被回應。
