# 戰鬥規則
- 單位可以選擇攻擊對手單位或直接攻擊玩家
- 由玩家指定攻擊目標
- 傷害在傷害結算後永久保留
- 單位一回合可以攻擊1次
- 剛進場不能發動攻擊，除非有卡牌效果說明可以直接攻擊

## 戰鬥反擊
- 當進攻單位攻擊其他單位時，被攻擊的單位會進行反擊，雙方同時造成傷害。
- 反擊不視為主動攻擊，不消耗該單位本回合的攻擊次數，且即使該單位本回合無法主動攻擊仍可反擊。
- 單位已經攻擊過而再被攻擊時還可反擊。
- 剛登場、不能主動攻擊的單位可以進行反擊。

## 戰鬥流程
- 單位攻擊單位: 宣告攻擊 → 選擇合法攻擊目標 → 攻擊回應窗口 → 處理「攻擊時」觸發效果 → 效果回應窗口 → 確認攻擊是否合法 → 處理「受到攻擊時」觸發效果 → 效果回應窗口 → 雙方同時造成戰鬥傷害 → 傷害結算 → 處理死亡 → 處理「死亡時」效果 → 處理「離場」效果 → 攻擊結束。
- 單位攻擊玩家: 宣告攻擊 → 選擇合法攻擊目標 → 攻擊回應窗口 → 處理「攻擊時」觸發效果 → 效果回應窗口 → 確認攻擊是否合法 → 處理「受到攻擊時」觸發效果 → 效果回應窗口 → 造成戰鬥傷害 → 傷害結算 → 勝負判定 → 攻擊結束。
