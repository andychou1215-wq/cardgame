# 核心玩法
- 玩家使用各種卡牌類型與策略與對方進行卡牌對決。

# 核心規則
- 每位玩家有25點生命值
- 起手牌5張，第一回合開始前可換牌(換牌數量不限)
- 每位玩家牌組最多可以存放45張卡牌
