# 回合流程
開始階段 → 抽牌 → 行動 → 戰鬥 → 結束

# 對局基本結構
- 採1v1回合制
- 隨機決定先手(採拋硬幣式)
- 一局理想時間為10~20分鐘
- 每回合消耗資源進行行動，資源點消耗完前行動次數任意。

# 先後手規則
先手玩家第一回合不抽牌。

# 回合開始階段
1. 處理「回合開始時」觸發
2. 結算相關效果
3. 處理神器耐久衰減
4. 移除「直到回合開始」效果
5. 執行狀態檢查
6. 執行勝負檢查

# 回合結束階段
1. 處理「回合結束時」觸發
2. 結算相關效果
3. 移除「直到回合結束」效果
4. 執行狀態檢查
5. 執行勝負檢查
6. 交給下一位玩家
