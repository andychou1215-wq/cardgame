# 關鍵字系統

- 〖登場〗：從手牌中使用後進入戰場時發動的能力。
- 〖離場〗：以任意方式從戰場離開時發動的能力。
- 〖迅擊〗：進入戰場的當回合即可進行攻擊。
- 〖庇護〗：敵方的單位卡僅可攻擊持有該能力的單位卡。
  - 若我方場上擁有數個〖庇護〗效果的單位，敵方可自由選擇其中一個持有〖庇護〗的單位進行攻擊。
- 〖吸血〗：透過主動攻擊實際給予傷害時，回復攻擊單位自身與該傷害等量的現有生命值。
  - 回復量以實際造成的傷害為準。
  - 回復後不可超過該單位最大生命值。
  - 反擊造成的傷害不視為主動攻擊，因此不觸發〖吸血〗。
- 〖格檔〗：每次受到戰鬥傷害時，使該次傷害減少 1 點，最低降至 0。
  - 可減少主動攻擊造成的戰鬥傷害與反擊傷害。
  - 不會減少 Spell、Ability 或其他卡牌效果直接造成的傷害。
- 〖迴避〗：持有該效果的單位卡不會被敵方的單位卡攻擊。
  - 具有〖迴避〗的單位不會出現在敵方單位卡的合法攻擊目標中。
  - 〖迴避〗只限制敵方單位卡的攻擊，不會阻止 Spell、Ability 或其他卡牌效果指定該單位。

# 關鍵字規則

- 單位效果中，〖庇護〗與〖迴避〗只能存在其中一個。

# 最大生命值規則

- 當單位的最大生命值增加 X 點時，其現有生命值同步回復 X 點。
- 此同步回復不可使現有生命值超過新的最大生命值。
- 最大生命值降低時不會造成治療；若現有生命值高於新的最大生命值，則降至新的最大生命值。
- 因翻面而使卡面基礎最大生命值增加時，也視為最大生命值增加並同步回復差額。
