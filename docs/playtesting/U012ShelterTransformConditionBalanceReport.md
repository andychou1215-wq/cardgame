# U012【庇護】翻面條件平衡測試報告

日期：2026-09-03

測試改動：U012「騎士團長」翻面條件由：

> 我方戰場上至少共有3個單位時翻至反面。

改為：

> 我方戰場上至少共有3個單位，且其中一個單位擁有【庇護】效果時翻至反面。

反面效果維持 `U012BackShelterExtensionBalanceReport.md` 的延長版不變。

## 結論

**新條件明顯降低並延後 U012 Transform，但幾乎沒有改變對局勝負；建議保留主題一致的條件，並停止把 U012 當成目前唯一的平衡槓桿。**

U012 Transform 率由 72.3% 降至 59.8%，少 12.5 個百分點；Transform 個體由 261 降至 216，少 45 次，平均 Transform 回合由 8.07 延後至 8.47。

但同策略 D001 勝率只由 80.0% 降至 79.5%（159/200，95% Wilson CI：73.4%–84.5%），Heuristic/Heuristic 維持 69%，Random/Random 由 91% 降至 90%。

相同種子的 400 場逐場配對比較更清楚：399 場勝者完全相同，只有 1 場由 D001 勝轉為 D002 勝，沒有任何反向翻轉。條件改動確實改變了 65 場的行動數、36 場的回合數，但大多不足以改變最終勝負。

新條件還產生一個補償效應：由於翻面前必須已有【庇護】，翻面後延長效果的覆蓋率從 56.3% 升至 98.6%。也就是說，U012 雖較少翻面，一旦翻面，反面效果幾乎總能以完整協同狀態生效。

## 規則與測試驗證

自動測試確認：

- 少於 3 個我方單位時不翻面，即使已有【庇護】。
- 有 3 個我方單位但沒有【庇護】時不翻面。
- 兩項條件同時成立時正常翻面。
- 既有反面 +1/+1 延長、不疊加及到期時間測試全部維持通過。

完整測試結果：110 passed。

## 方法

與對照版使用完全相同的模擬設定：

- 隨機種子：`20260902`
- 4 種策略配對
- 每種配對 50 組鏡像
- 每組交換 D001／D002 的 P1、P2 座位
- 總計 400 場
- 最大行動數：1,000

400 場全部正常完成，沒有 stalled、invalid action 或 action limit。P1 勝 203 場，勝率 50.8%，未觀察到實質座位偏差。

本次另外依 `pairing + mirror_group + mirror_side + game_seed` 將新舊 400 場逐一配對，以區分淨勝率變化與個別對局路徑變化。

測試資料位於 `playtest_data/analysis/u012_transform_shelter_requirement_20260903/`：

- `mirrored_games.csv`：400 場鏡像結果
- `metrics.json`：牌組、場面、傷害、治療、Transform 與延長效果指標
- `u012_extension_targets.csv`：延長效果目標分布
- `paired_comparison.json`：與上一版相同種子的逐場勝負比較

新條件讓較少數的 Transform 幾乎都能延長效果。這項協同補償了翻面頻率下降的一部分：原版可能在沒有【庇護】時先翻面，新版則等待到能充分發揮反面延長效果時才翻面。

仍有 3 次 Transform 沒有其他可延長的【庇護】目標。條件允許 U012 自身成為唯一擁有【庇護】的單位，但反面第一段只增益「其他單位」，因此來源自身沒有可延長的 +1/+1。

## 原因判斷

新條件大幅改變 Transform 指標卻幾乎不改變勝率，最可能的原因是：

1. 被阻止的 45 次 Transform 多半發生在本來就不依賴反面效果決定勝負的對局。
2. 一旦翻面，延長效果覆蓋率由 56.3% 升至 98.6%，提高了每次成功 Transform 的平均品質。
3. U012 正面登場的本回合 +1/+1 完全不受新條件影響，主要即時價值仍然保留。
4. D001 的領袖傷害只下降 0.008／場，顯示主要終結能力來自整副牌，而不是 U012 翻面本身。
5. Random/Random D001 勝率仍達 90%，代表 D001 與 D002 的基礎強度差距尚未解決。

## 建議下一步

**建議保留本次翻面條件。** 它讓 U012 的主題與反面獎勵一致，也把過高的 72.3% Transform 率壓到 59.8%，本身是合理的設計改善。

但不建議繼續只調整 U012 的翻面門檻。相同種子的 400 場中，45 次 Transform 消失卻只翻轉 1 場勝負，已提供明確證據：目前 D001 的失衡不是單靠 U012 Transform 造成。

下一輪建議：

1. 使用既有卡牌歸因資料重新排序 D001 的 U006、U002、U011，選出下一個單卡測試目標。
2. 優先檢查能直接形成領袖壓力或高交換效率的效果，而不是再削減 U012 的防守延長。
3. 每次仍只修改一張卡的一個變因，並以相同種子做逐場配對比較。

若希望繼續測 U012，唯一值得單獨驗證的變因是正面登場 +1/+1，因為它不受新翻面條件限制；但在動手前應先和其他 D001 高影響卡做歸因比較。
