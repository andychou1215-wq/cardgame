# U011 費用 8：2,000 場 Heuristic 鏡像複驗報告

日期：2026-09-03

## 結論

**2,000 場複驗結果支持保留 U011 費用 8；Heuristic/Heuristic 的 D001 勝率為 51.2%，目前可視為接近五五波。**

前次 100 場 Heuristic/Heuristic 探索樣本得到 55%。本次沿用完全相同的亂數序列，前 100 場逐列重現原結果；新增的後續 1,900 場則為 D001 969 勝、D002 931 勝，D001 勝率 51.0%。合併後為 1,024 / 2,000（51.2%）。

以每個鏡像組作為獨立觀察單位估計，D001 勝率的 95% 信賴區間為 49.2%–53.2%，包含 50%。因此 55% 是可重現的小樣本結果，但不是擴大樣本後的穩定點估計。

## 方法

- 卡牌版本：U011 費用 8，反面授予暫時【庇護】。
- Bot：P1、P2 均為 Heuristic。
- 牌組：D001 與 D002。
- 鏡像組：1,000 組。
- 每組使用相同遊戲與 Bot 種子，交換 D001／D002 的 P1、P2 座位。
- 總場數：2,000。
- 種子：`20560911`。
- 每場最大行動數：1,000。

`20560911` 是前次標準 400 場測試中 Heuristic/Heuristic 配對實際使用的種子。本次將相同序列由 50 組擴充到 1,000 組，因此前 50 組／100 場可以直接檢查再現性。

## 平衡判斷

1. **保留 U011 費用 8。** 大樣本 Heuristic/Heuristic 勝率已落在 49.2%–53.2% 的鏡像組層級區間。
2. **不要再提高 U011 翻面門檻。** 現在追加第二項削弱，較可能把策略對局推向 D002，而不是修正仍存在的明確失衡。
3. **不要用 Random/Random 的失衡否定本結果。** Random Bot 不會穩定利用 D002 的鋪場與節奏；平衡判斷應優先採用能執行策略的 Heuristic 對局。
4. **下一階段改做真人測試。** 需要確認 8 費 U011 是否有合理的等待回報、是否過度卡手，以及 D001／D002 的決策品質是否真的接近，而不只是自動策略勝率相近。
