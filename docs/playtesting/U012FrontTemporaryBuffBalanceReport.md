# U012 正面暫時增益平衡測試報告

日期：2026-09-02

測試改動：U012「騎士團長」正面登場效果保留其他友軍攻擊力與最大生命值 +1，但持續時間由永久改為到本回合結束。

對照報告：`PostInstrumentationBalanceReport.md`

## 結論

**本次改動可保留，但不足以解決 D001／D002 的主要平衡差距。**

在相同策略的公平比較中，D001 勝率僅從 82.0% 降至 81.5%（163/200，95% Wilson CI：75.5%–86.3%），只減少 0.5 個百分點。Heuristic/Heuristic 從 73% 降至 71%，但 Random/Random 從 91% 升至 92%，沒有形成跨策略一致的改善。

U012 仍有 72.1% 的 Transform 率。它在符合三個友軍條件後，很快取得背面的永久群體攻擊與最大生命增益，因此正面增益暫時化只縮短第一層增益的持續時間，沒有移除主要的永久累積來源。

## 方法

沿用改動前報告的相同測試條件：

- 隨機種子：`20260902`
- 4 種策略配對
- 每種配對 50 組鏡像
- 每組交換 D001／D002 的 P1、P2 座位
- 總計 400 場
- 最大行動數：1,000

400 場全部正常完成，沒有 stalled、invalid action 或 action limit。P1 勝率為 50.0%，可排除座位偏差。

## 原因判斷

本次改動影響有限，最可能的原因是：

1. U012 通常在已有多個友軍時登場，正面暫時增益仍能完整影響當回合戰鬥。
2. `unit_count_at_least = 3` 條件容易在登場後立刻達成。
3. Transform 後 E021／E022 再次給予其他友軍攻擊力與最大生命值永久 +1。
4. 正面最大生命暫時增加仍會立即同步治療，保留短期交換價值。
5. D001 的 U011、U006、U002 等戰鬥核心未受本次修改影響。

## 建議下一步

下一輪應直接測試 U012 背面的永久群體增益，且一次只改一個變因。

推薦方案：

- 保留正面「其他友軍 +1/+1 到本回合結束」。
- 將背面 E021／E022 改為「其他友軍 +1/+1 到本回合結束」，取消永久累積。

替代方案：

- 背面仍為永久，但只指定一個其他友軍。
- 或保留群體永久效果，但只增加攻擊或最大生命其中一項。

下一輪仍使用相同種子與 400 場設計。若 Heuristic/Heuristic D001 勝率未降至 60% 以下，再檢查 U006、U002、U011；不建議先全面強化 D002。
