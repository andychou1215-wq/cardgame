# U011 反面暫時【庇護】平衡測試報告

日期：2026-09-03

## 改動

U011「遺跡石像」反面效果由：

> 翻面時: 指定我方一個其他單位獲得永久【庇護】。

改為：

> 翻面時: 指定我方一個其他單位獲得【庇護】持續到對手回合結束。

結構化效果 E018 的 `duration` 同步由 `permanent` 改為 `until_opponent_turn_end`。費用、攻擊力、生命值、正面關鍵字與翻面條件皆未改動，因此本次為單變量測試。

## 結論

**這項改動成功移除永久【庇護】的累積與記憶負擔，但 400 場探索性模擬沒有顯示可量測的整體削弱效果。**

同策略對局的 D001 勝率前後皆為 79.5%；Heuristic/Heuristic 維持 69%，Random/Random 維持 90%。全部 400 場只有 5 場改變勝者，其中 3 場由 D002 轉為 D001、2 場由 D001 轉為 D002，淨結果反而讓 D001 多 1 勝。這個 0.25 個百分點差異只是一場對局，不應解讀為實際強化。

改動仍有實際介入對局：52 場行動數改變、23 場回合數改變。較合理的判讀是「效果會改變局部攻擊路徑，但 U011 的永久授予不是目前 D001 勝率過高的主要來源」。

## 驗證

- 新增 U011 效果資料與完整持續時間生命週期測試。
- 確認指定目標是其他我方單位，且 U011 自身不會被選取。
- 確認目標在我方回合結束後仍保有【庇護】。
- 確認效果在對手回合結束時移除，且不會寫入永久關鍵字。
- 針對性測試：8 passed。
- 完整測試：111 passed。

## 測試方法

- 基準：U012 已採用【庇護】翻面條件、U011 仍永久授予【庇護】的最近版本。
- 候選：僅將 U011 E018 持續時間改為 `until_opponent_turn_end`。
- 種子：`20260902`。
- 四種策略配對：Heuristic/Heuristic、Heuristic/Random、Random/Heuristic、Random/Random。
- 每種配對 50 組鏡像，每組交換 D001／D002 座位。
- 總計 400 場，最大行動數 1,000。
- 使用 `pairing + mirror_group + mirror_side + game_seed` 將新舊結果逐場配對。

400 場全部正常完成，沒有 stalled、invalid legal action 或 action limit。P1 勝 204 場（51.0%），沒有明顯座位偏差。

## U011 實戰曝光

| 指標 | 新版結果 |
|---|---:|
| 打出的 U011 個體 | 345 |
| 至少打出 U011 的對局 | 258 |
| 翻面的 U011 個體 | 233 |
| 至少有 U011 翻面的對局 | 191 |
| 每個打出個體的翻面率 | 67.5% |
| 平均翻面回合 | 9.25 |
| U011 翻面對局中的 D001 勝率 | 143 / 191（74.9%） |

U011 有足夠高的出牌與翻面曝光，這次結果不是因為卡牌從未進入實戰。不過「翻面時勝率」帶有明顯的存活與局勢選擇偏差，只能確認曝光，不能用來推論因果強度。

目前 `add_keyword` 結算沒有獨立的 effect-applied telemetry，因此無法直接統計 233 次翻面中有多少次成功找到其他友軍，以及暫時【庇護】實際保護了多少次攻擊。這不影響勝負與路徑比較，但限制了機制覆蓋率分析。

這些變化都很小，而且部分方向與直覺相反。永久【庇護】移除後，攻擊目標限制改變會連鎖影響 Bot 的交換、存活單位與後續抽牌／出牌選擇，因此不能把 +0.042 場攻或 +0.145 領袖傷害視為卡牌被強化；逐場勝負只有一場淨差更能反映目前的證據強度。

## 平衡判斷與建議

1. **可保留本次文字。** 暫時效果更容易追蹤，也避免一張中後期單位永久改寫後續所有攻擊目標。
2. **不要把本次改動視為已解決 D001 失衡。** 同策略 D001 仍為 79.5%，遠高於可接受的接近五五波範圍。
3. 若下一輪仍調整 U011，應只測一個更直接的強度槓桿：費用 7 → 8，或翻面門檻由累計受到 4 點傷害提高至 5 點；兩者不要同時修改。
4. 下一輪沿用相同 400 場種子做探索性 A/B。若同策略勝率出現明確下降，再以至少 2,000 場 Heuristic/Heuristic 鏡像複驗。
5. 若要分析【庇護】機制本身，先補 `add_keyword` 成功結算、目標卡與到期事件 telemetry，才能量測授予覆蓋率與實際攔截攻擊數。
